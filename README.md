# Celebrity Solitaire

A separate Klondike Solitaire game featuring reusable photographs of Mac Miller on Jacks, Tana Mongeau on Queens, Flea on Kings, and Tiger Woods on Aces.

Open `index.html` in a browser. Click cards to select them and click a destination pile to move them. Double-click an available card to send it to a legal foundation. Use **New Deal** for a reshuffle or **Restart** to replay the current deal.

Photo licenses and source links are recorded in [ATTRIBUTION.md](ATTRIBUTION.md).
